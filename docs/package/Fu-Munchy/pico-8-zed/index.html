#Pico-8 language server for Zed

Pico-8 is a fantasy console by Lexaloffle, where the language is built on version 5.2 of Lua.

This extension provides pico-8 language server for Zed code editor. It uses the tree-sitter grammar from tree-sitter lua and reuses grammar code from the Zed Lua extension.

The code found in src/lib.rs is in its entirety generated by AI.

For me, this project is a step into zed extension building, and learning rust. The extension was built mainly to learn how rust is used to make zed extensions. AI was used to learn how the zed_extension API should be used. I will be inspecting this code closely while continuing to learn rust - and perhaps re-write this extension in the future.

For now, I will leave the extension as is.

#Installation

#From source

The extension needs to be installed via downloading the source code (in a chosen directory), and installing it as a Dev Extension in Zed.

From there, open a .lua file, and select the pico8-ls as the language server and set the language of the file to Pico-8. This will enable the correct language server and appropriate syntax highlighting, respectively.
