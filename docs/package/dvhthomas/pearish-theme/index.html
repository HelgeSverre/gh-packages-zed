#Install

  1. Open Zed
  2. Open the extensions panel (cmd+shift+x)
  3. Search for "Pearish"
  4. Click Install
  5. Select Pearish Light or Pearish Dark in your theme settings

#Manual Install

Clone this repo into your Zed extensions directory:

git clone https://github.com/dvhthomas/pearish-theme \
  ~/.local/share/zed/extensions/installed/pearish-theme

Then restart Zed and select the theme.
