#Installation

  1. Install the extension from the Visual Studio Marketplace
  2. Open the command palette (Ctrl+Shift+P) and select "Preferences: Color Theme"
  3. Select "Blank Moonlight"

#Customization

You can customize the theme by editing the settings.json file. To do this, open the command palette (Ctrl+Shift+P) and select "Preferences: Open Settings (JSON)". Then, edit the settings.json file.
