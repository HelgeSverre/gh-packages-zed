#New Darcula for Zed IDE

Clean take on the JetBrains Darcula theme. Includes a Dark, Darker, and Light theme.
Also available as a VS Code extension.

#Install via Zed Extensions

  1. Open Zed
  2. cmd+shift+p and select zed: extensions
  3. Search/select New Darcula Theme and Install

#Install Manually

  1. Download newdarcula.json
  2. Put into ~/.config/zed/themes/
