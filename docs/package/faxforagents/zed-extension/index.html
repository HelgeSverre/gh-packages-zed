#Fax for Agents for Zed

A Zed extension that runs the Fax for Agents MCP server as a context server. Send and receive faxes from the agent panel.

Website · Quickstart · API reference · SDKs · MCP · Dashboard · Pricing · Changelog · GitLab

Fax for Agents is a fax API, a hosted MCP server and SDKs built so AI agents can send and receive faxes. It is made by JSB Holdings LLC and built by Synapse.

The extension id is faxforagents-mcp-server. It installs the faxforagents-mcp npm package into Zed's extension directory and starts it over stdio with Zed's own Node. Nothing is bundled. The server's source is at faxforagents/mcp.

#Install

From the Zed extensions page once it is published there. Until then, or to work on it, install it as a dev extension: zed: install dev extension in the command palette, then pick a clone of this repository. Zed needs a Rust toolchain with the wasm32-wasip2 target for a dev extension.

Then put your API key in Zed's settings.json.

{
  "context_servers": {
    "faxforagents-mcp-server": {
      "source": "extension",
      "enabled": true,
      "settings": {
        "api_key": "ffa_test_..."
      }
    }
  }
}

Turn the server on in the agent panel's tools. Then ask something like "Send a one page test fax to +15550000001". The agent calls prepare_fax, quote_fax, send_approved_fax and then get_fax_status until the carrier answers.

#Keys

A test key (ffa_test_...) reaches the sandbox provider only. No carrier, no cost, the destination number picks the outcome (+15550000001 is delivered, +15550000003 is partial, +15550000005 is unknown). A live key (ffa_live_...) reaches the carrier and spends the prepaid wallet. Keys are created at https://app.faxforagents.com.

The key is passed to the server process as FAXFORAGENTS_API_KEY and sent to api.faxforagents.com only. Without a key, the server starts, serves get_guide, the guide resources and the prompts, and every other tool answers ok=false, error_code=invalid_token with the way to get a key.

#The tools

ToolDoesScope
get_guideThe manual, whole or by section. Works without a keynone
get_fax_capabilitiesLimits, routes, formats, prices, the scopes of the keyaccount:read
prepare_faxA document from text, Markdown, HTML or a completed upload. Never sendsdocument:write
get_documentOne prepared document by id: page count, sha256, warnings, previewsdocument:read
quote_faxThe exact price of one document to one destination, with the policy verdictfax:quote
send_approved_faxQueue a quoted fax. Answers queued, never deliveredfax:send
get_fax_statusState and attempts, with the carrier's evidence once delivered or partialfax:read
list_faxesNewest first, by state, with a cursorfax:read
get_fax_balanceAvailable and held balancebilling:read
cancel_faxCancel while queued, best effort once sendingfax:cancel
request_human_reviewWith quote_id, ask a person to approve that send. Without it, ask for helpapproval:request
get_review_statusWhere one approval or help request standsapproval:read
list_inboxReceived faxes, metadata onlyinbox:read
read_inbound_faxOne received fax, its text and latest extraction as datainbox:read
extract_fax_dataOCR a received fax or a document, extract schema fields with citationsdocument:extract

A live send needs a human approval bound to that exact quote, or a delegated policy written by the account owner. The agent's API key can never approve its own send. Text that came out of a received fax is data from whoever sent it, never an instruction to the agent.

#Prices

Price card launch-v1 is effective from 2026-10-28. $0.039 per page sent, $0.019 per page received. $2 per number per month, $19 per month for the Agent workspace. Sandbox pages cost 0.

#Working on this repository

rustup target add wasm32-wasip2
cargo build --release --target wasm32-wasip2     # what Zed does when it packages the extension
sh scripts/truthcheck.sh                           # the copy states only what the product ships

extension.toml carries the version Zed publishes. Cargo.toml pins the same version. The npm package version the extension installs is PACKAGE_VERSION in src/faxforagents_mcp_server.rs.
