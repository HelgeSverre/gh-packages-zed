#Adaltas theme

The Adaltas theme is an elegantly designed dark theme with sharp contrast colors for the Zed editor. The theme is MIT licensed.

#Developpers

Please report any issue and improvement request on the GitHub.

A penpot file is located inside the [./assets] folder to preview and tweak the colors.

#Colors

#UI

It extends Andromeda with alternative colors. New colors are written in uppercase to differentiate them from the original theme.
