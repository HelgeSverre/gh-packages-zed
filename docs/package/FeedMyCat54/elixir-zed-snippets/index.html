#Elixir Code Snippets

This repository contains a collection of Elixir code snippets designed to be used in the Zed editor. Inspired from the VSCode Elixir Snippets extension.

#Migration Notes

Some of the original snippets have been modified either because they contain VSCode features not available in Zed or because they generate deprecated code :) If you have a way to improve/enhance a snippet, please open an issue or pr for it.

#Installation

  1. In Zed go to the extensions page.
  2. Search for Elixir Snippets.
  3. Click Install.
