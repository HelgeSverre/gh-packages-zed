#Pure Black High Contrast

A pure black, high-contrast theme for Zed designed for developers who want a true #000000 editor background, bright syntax highlighting, and a clean dark interface.

#Features

  • True black #000000 editor background
  • High-contrast white text
  • OLED-friendly dark interface
  • Bright, readable syntax highlighting
  • Subtle UI borders and surfaces
  • Clear active line and selection states
  • Color-coded Git changes and diagnostics
  • Matching terminal color palette
  • Minimal visual distractions

#Installation

#From Zed Extensions

Open Zed and go to:

Extensions → Search for "Pure Black High Contrast" → Install

Then select the theme from:

Settings → Theme → Pure Black High Contrast

#Manual Installation

Clone this repository:

git clone https://github.com/Dhanush-S-Gowda/zed-theme-Pure-Black-High-Contrast.git

Then install it as a development extension in Zed.

Open the command palette and run:

zed: extensions

Choose Install Dev Extension and select the cloned repository.

#Why This Theme?

Many dark themes use dark gray backgrounds such as #111111, #181818, or #1E1E1E.

Pure Black High Contrast uses an actual:

#000000

background for the editor and terminal, while keeping surrounding UI elements subtly separated using near-black shades.

The result is a theme designed to feel:

  • dark without looking washed out
  • high contrast without being harsh
  • colorful without being distracting
  • especially suited to OLED displays

#Syntax Highlighting

The syntax palette is designed around clear visual separation:

  • Keywords — Purple
  • Functions — Blue
  • Types — Cyan
  • Strings — Green
  • Numbers / Constants — Yellow
  • Properties / Parameters — Soft Red
  • Comments — Gray
  • Operators — Cyan
