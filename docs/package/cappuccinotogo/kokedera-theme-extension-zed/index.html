#Kokedera Theme

Bring the quiet of a moss-covered temple into your editor. Kokedera offers nine hand-tuned color themes inspired by forest greens, weathered stone, and warm lantern light — seven dark palettes and two light palettes.

kokedera.style — walk through the temple, explore its nine palettes, and find the matching file icons.

#About

Kokedera is a quiet temple among the roots of the World Tree, where moss covers the stone paths and a small golem tends the lanterns.

Kokedera Theme brings all nine palettes to Zed. Choose a different hour, season, or weather in the same place.

#Variants

ThemeMood
Kokedera MorningLight — warm paper grounds, greens that read like ink
Kokedera DuskDark — deep forest greens, weathered stone and soft lantern light
Kokedera NightDark — near-black grounds, brighter greens and warm lantern contrast
Kokedera SpringDark — fresh greens and cherry blossom
Kokedera SummerDark — dense, saturated greens and a teal stream
Kokedera AutumnDark — rust, amber and ember over dark earth
Kokedera WinterLight — cool pale grounds, steel blue and a quiet red
Kokedera RainDark — wet teal, blue-green shadows and reflected lantern warmth
Kokedera MistDark — soft, desaturated greens and blue-grey distance

#Installation

  1. Open Zed
  2. Open the command palette: Cmd+Shift+P (macOS) / Ctrl+Shift+P (Linux and Windows)
  3. Search for "zed: extensions"
  4. Search for "Kokedera Theme"
  5. Click Install
  6. Open command palette again and search for "theme selector: toggle"
  7. Select a variant, such as Kokedera Dusk

#Local development

This extension contains only theme data; this repository has no compilation or packaging step. In Zed, run zed: install dev extension and select this repository directory. See Developing Extensions for the development workflow.

The golem logo appears in this README. Zed's extension manifest has no extension logo field.
