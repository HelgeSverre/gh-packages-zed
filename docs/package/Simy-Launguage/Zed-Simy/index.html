#zed-simy

English | 简体中文

Zed editor support for Simy, a DSL for Minecraft datapack development.

This extension is grammar-only: it ships the Simy Tree-sitter grammar together with highlighting and editor integration queries. No language server yet.

#Features

FeatureQuery
Syntax highlightinghighlights.scm
Bracket matchingbrackets.scm
Auto-indentationindents.scm
Code foldingfolds.scm
Document outlineoutline.scm
Local scopeslocals.scm

Simy keywords, Minecraft atoms (selectors, coordinates, namespaced IDs, block states, raw NBT), string interpolation and $ references are all highlighted.

#Installation

Once published to the Zed extension registry:

  1. Open the command palette (zed: extensions).
  2. Search for Simy and install it.

#Installing as a development extension

  1. Clone the repositories side by side (see Requirements).
  2. In Zed, run zed: install dev extension and select this directory.

Zed will build the extension and compile the grammar referenced in extension.toml.

#Requirements

  • Zed.

  • Rust toolchain with the wasm32-wasip1 target (only for dev installs):

    rustup target add wasm32-wasip1

#How it is wired

# extension.toml
[grammars.simy]
repository = "https://github.com/Simy-Launguage/tree-sitter-simy"
rev = "bcc6d90a54f83b727d8f60aa5158e4192a642e59"

The language is declared in languages/Simy/config.toml with path_suffixes = ["simy"], so files ending in .simy use this language.

The grammar lives in its own repository so that editors other than Zed can consume it. When you change query or config files, rebuild the dev extension — Zed reads them at install time.
