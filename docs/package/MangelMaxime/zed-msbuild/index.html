#Zed MSBuild LSP

MSBuild language server for Zed.

IntelliSense (completions, diagnostics, hover) is powered by msbuild-project-tools-server. The extension downloads it automatically on first use.

It requires the .NET SDK (8.0+) to be installed and available as dotnet on PATH.

#Languages

The language server attaches to languages defined by other extensions:

LanguageFilesExtension
C# Project File.csprojC#
MSBuild File.proj, .props, .targetsC#
F# Project File.fsprojF#

To use it with other MSBuild files, map their extensions to MSBuild File in your Zed settings:

{
  "file_types": {
    "MSBuild File": ["vbproj", "vcxproj", "sqlproj", "wixproj", "shproj", "njsproj", "pyproj", "tasks", "pubxml"]
  }
}

#Developing locally

  1. Open Zed.
  2. zed: install dev extension (from the command palette) and select this directory.
  3. Install the C# and F# extensions.
  4. Open a .csproj/.props/.targets file to see it in action.

#Contributing

This repository uses Conventional Commits. Commit messages are validated by a Husky commit-msg hook running EasyBuild.CommitLinter.

After cloning, enable the hook once (requires a .NET SDK on PATH):

dotnet tool restore
dotnet husky install

Accepted commit types: feat, fix, ci, chore, docs, test, style, refactor, perf, revert, build.
