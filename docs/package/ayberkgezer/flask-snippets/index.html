#Flask Snippets

Flask snippets for Zed IDE.

#Installation

#Method 1

  1. Go to Extensions menu in Zed IDE
  2. Search for "flask-snippets"
  3. Click "Install"

#Method 2

  1. Clone this repo:
git clone https://github.com/ayberkgezer/flask-snippets
  1. Go to Extensions menu in Zed IDE
  2. Click "Install Dev Extension"
  3. Select the folder you cloned
