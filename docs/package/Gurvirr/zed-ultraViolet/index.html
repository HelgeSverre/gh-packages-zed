#Usage

  1. Open Zed
  2. Navigate to the settings menu ( Ctrl+Shift+X )
  3. Search for 'ultraViolet' & click install
  4. Select 'ultraViolet' in the theme selector ( Ctrl+K+T )
  5. Enjoy!
