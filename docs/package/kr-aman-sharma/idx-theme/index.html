#IDX Theme for Zed

A set of themes for the Zed editor inspired by Google's Project IDX online editor.

This extension provides three variants:

  • IDX Dark – rich, contrasty dark theme for everyday coding
  • IDX Dark Flat – a flatter dark variant with reduced elevation
  • IDX Light – a clean, bright theme suited for well‑lit environments

#Installation

Once this extension is available on the Zed extension marketplace:

  1. Open Zed.
  2. Go to Extensions.
  3. Search for "IDX Theme".
  4. Click Install.

For manual installs from source, clone this repository into your Zed extensions directory and restart Zed.

#Usage

After installing the extension:

  1. Open Zed Settings.
  2. Navigate to Themes.
  3. Select one of the available themes:
    • IDX Dark
    • IDX Dark Flat
    • IDX Light

Switch between them based on your ambient lighting or personal preference.
