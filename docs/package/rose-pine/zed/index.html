#Rosé Pine for Zed

All natural pine, faux fur and a bit of soho vibes for the classy minimalist

#Usage

  1. Install the Rosé Pine extension from Zed extensions
  2. Select your desired variant from the theme selection menu

#Contributing

  • Modify src/template.json
  • Run npx @rose-pine/build -t ./src/template.json -f hex -o themes/ to build
