#Spring Boot Properties for Zed

A Zed extension that provides snippets for application.properties files in Spring Boot projects.

#Installation

  1. Open Zed
  2. Press cmd+shift+x / ctrl+shift+x to open the Extensions page
  3. Search for spring-boot-properties
  4. Click Install

#Usage

Open any application.properties file and start typing a prefix. Select a snippet from the autocomplete dropdown using tab or enter.

#Snippets

Most snippets are documented and based on the official Spring Boot documentation. They cover common configuration areas including server, datasource, JPA, logging, security, caching, messaging, and more.

#Contributing

Contributions are welcome! If you find a missing property or want to improve an existing snippet, feel free to open an issue or submit a pull request on GitHub.
