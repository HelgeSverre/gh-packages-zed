#zed-jsonnet

Jsonnet language support for Zed editor.

#Settings

The jsonnet-language-server settings can be changed in the lsp section of your settings.json.

{
  "lsp": {
    "jsonnet-language-server": {
      "settings": {
        "log_level": "info",
        "resolve_paths_with_tanka": true
      }
    }
  }
}
