# Codigrate Themes for Zed

A carefully crafted collection of Zed themes inspired by nature and iconic cities around the world. Each theme is designed with balance, readability, and long coding sessions in mind, blending distinctive atmospheres with thoughtfully tuned colors that make your editor feel both elegant and comfortable. Whether you prefer calm, light environments or deep, immersive dark palettes, these themes aim to make your coding experience visually inspiring and pleasantly focused.

#Getting Started

  1. Install Zed on your system (zed.dev).
  2. In Zed, open Extensions (Cmd+Shift+X, Ctrl+Shift+X on Linux), search for Codigrate Themes and click Install; the twelve free themes arrive together.
  3. Open the theme selector with Cmd+K Cmd+T (Ctrl+K Ctrl+T on Linux) and pick a theme by name.

Prefer a single theme file? Copy the theme's themes/<name>.json from this repository into ~/.config/zed/themes/ (the same path on macOS and Linux) and it shows in the selector right away.

#Premium themes

Some themes are premium: they are sold on codigrate.com as a one-time download (pay with Stripe, no account needed) and are marked (Premium) below with a Buy badge. The download holds the same theme file as a free theme and installs the same way (~/.config/zed/themes/, or Install Dev Extension on the unzipped folder); the files themselves are not in this repository.

#Notes

  • The themes follow Zed's theme schema v0.2.0: UI, editor, syntax and the built-in terminal (16 ANSI colors).
  • The syntax palette matches the Codigrate VS Code, Sublime Text and JetBrains ports of the same theme; the terminal colors match the Ghostty, iTerm2 and macOS Terminal ports.
  • Theme appearance may vary slightly depending on your operating system and font rendering.
