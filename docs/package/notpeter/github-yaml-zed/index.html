#GitHub YAML Zed Extension

Zed extension supporting GitHub YAML configuration files.

Features of this extension

  • Advanced GitHub Workflow YAML syntax highlighting (${{ }} and run: blocks).
  • Schema definitions for 9 GitHub YAML configuration file formats
    • GitHub Workflow, Action, Funding, Dependabot, Release, Issues, etc
  • Adds schema definitions for 12+ common YAML/JSON configuration file formats
    • prettierrc, gitlab-ci.yml, renovate.json, vercel.json, etc.

#Installation

Open zed: extensions from the command palette in Zed and search for GitHub YAML,

Or clone this repository and spawn zed: install dev extension.

#Required Settings

You must associate GitHub Workflow language with the appropriate globs:

  1. Open Zed command palette (cmd-shift-p / ctrl-shift-p)
  2. Spawn zed::OpenSettingsFile
  3. Add the following to your Zed settings.json
{
  "file_types": {
    "GitHub Workflow": [
      "**/.github/workflows/*.{yml,yaml}",
      "**/.github/actions/**/action.{yml,yaml}",
    ],
  },
}

#Git Firefly Extension

I also recommend the excellent Git Firefly extension which provides Zed languages for .gitattributes, .gitconfig,, .gitignore, etc.

Don't forget to add it's file_types associations as well:

{
  "file_types": {
    // Git Firefly extension
    "Git Attributes": ["**/{git,.git,.git/info}/attributes"],
    "Git Config": ["*.gitconfig", "**/{git,.git/modules,.git/modules/*}/config"],
    "Git Ignore": ["**/{git,.git}/ignore", "**/.git/info/exclude"]
  }
}

#Alternatives

NOTE

Consider adding explicit # $schema= directives to the top of your YAML files and "$schema": "" in your JSON files so your editor can automatically validate schemas without requiring configuration like that provided by this extension.

For a GitHub Actions Workflow file use:

# $schema=https://json.schemastore.org/github-workflow.json

Or in a vercel.json:

{
  "$schema": "https://openapi.vercel.sh/vercel.json"
}

#Features

  • Adds GitHub Workflow language:
    • base tree-sitter-yaml identical to Zed YAML language
    • injection of tree-sitter-ghactions for ${{ }} blocks
    • injection of tree-sitter-bash for run: blocks
    • injection of tree-sitter-javascript for actions/github-script script: blocks
    • injection of tree-sitter-nim-format-string for format placeholders: ${{ format('hi {0}', 'Bob') }}
  • JSON Schema settings to support auto-complete, validation and hover docs for:
    • GitHub Workflow: .github/workflows/*.{yml,yaml}
    • GitHub Action: .github/actions/**/action.{yml,yaml}
    • GitHub Funding: .github/FUNDING.yml
    • GitHub Discussions Templates: .github/DISCUSSION_TEMPLATE/*.yml
    • GitHub Issue Templates: .github/ISSUE_TEMPLATE/*.yml
    • GitHub Issue Configuration: .github/ISSUE_TEMPLATE/config.yml
    • GitHub Release Configuration: .github/release.yml
    • GitHub Dependabot Configuration: .github/dependabot.yml
    • Citation File Format: CITATION.cff
    • GitLab CI: .gitlab-ci.{yml,yaml}, *.gitlab-ci.{yml,yaml}
    • pre-commit-config: .pre-commit-config.{yml,yaml}
    • pre-commit-hooks: .pre-commit-hooks.{yml,yaml}
    • CircleCI: .circleci/config.{yml,yaml}
    • Render: render.{yml,yaml}
    • Azure Pipelines: azure-pipelines.{yml,yaml}
    • Buildkite: buildkite.{yml,yaml,json}
    • GoReleaser: .goreleaser.{yml,yaml}
    • Vercel: vercel.json
    • MkDocs: mkdocs.{yml,yaml}
    • Renovate: renovate.json
    • Prettier: .prettierrc, .prettierrc.{json,yml,yaml}
    • Biome: biome.{json,jsonc}

#LSP settings

The extension registers its own yaml-language-server instance under the LSP name github-yaml-language-server. This is only used for the GitHub Workflows language.

The schema associations are injected as language server settings and can be found here:

  • schemas/yaml-language-server.json
  • schemas/json-language-server.json
  • schemas/github-yaml-language-server.json

User settings are deep-merged on top of the bundled defaults, so you can add your own schemas or disable features without losing the bundled schemas.

See Zed YAML Language Docs and yaml-language-server settings docs for more.
