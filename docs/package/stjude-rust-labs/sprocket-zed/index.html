# sprocket-zed

WDL language support for Zed via the Sprocket LSP.

Request Feature · Report Bug

#🏠 Overview

sprocket-zed provides comprehensive WDL support for the Zed editor, powered by the Sprocket language server.

#🎨 Features

  • LSP Integration. Completions, diagnostics, hover documentation, go-to-definition, and references powered by Sprocket.
  • Syntax Highlighting. Full support for WDL 1.0 through 1.3 via tree-sitter-wdl.
  • Bash Injection. Command blocks are highlighted as bash.
  • Auto-Download. Automatically downloads the latest Sprocket release if not found on PATH.

#📚 Getting Started

#Installation

  1. Clone this repository:

    git clone https://github.com/stjude-rust-labs/sprocket-zed.git

  2. In Zed, open the command palette (Cmd+Shift+P) and run zed: install dev extension.

  3. Select the cloned sprocket-zed directory.

  4. When prompted, trust the worktree to start the language server.

The extension will automatically download the latest Sprocket release. To use a locally installed binary instead, ensure sprocket is on your PATH or set the binary.path option below.

#Configuration

Configure the extension in your Zed settings.json under the lsp.sprocket key:

{
  "lsp": {
    "sprocket": {
      "binary": {
        "path": "/path/to/sprocket"
      },
      "settings": {
        "lint": true,
        "outputLevel": "verbose",
        "checkForUpdates": true
      }
    }
  }
}
SettingTypeDefaultDescription
binary.pathstring—Path to a locally installed Sprocket binary
lintboolfalseEnable additional linting checks
outputLevelstring"quiet"Server output level: "quiet", "verbose", or "trace"
checkForUpdatesbooltrueCheck for new Sprocket releases on startup
