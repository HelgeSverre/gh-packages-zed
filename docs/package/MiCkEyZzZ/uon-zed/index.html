#uon-zed

Расширение для редактора Zed, добавляющее поддержку формата данных УОН (Универсальная Объектная Нотация / Universal Object Notation).

#УОН — что это?

УОН — это русскоязычный формат представления структурированных данных, вдохновлённый JSON. Ключевые слова и синтаксис ориентированы на русский язык.

#Синтаксис

{
  имя: "Вася",
  возраст: 25,
  холост: истина,
  дети: пусто,
  дата_рождения: 1999-01-15,
  время_в_пути: 1ч30мин,
  заметка: /* многострочный
               комментарий */,
  // однострочный комментарий
  адрес: {
    город: "Москва",
    индекс: 101000
  },
  телефоны: [
    "+7-900-123-45-67",
    "+7-901-234-56-78"
  ]
}

#Поддерживаемые типы данных

ТипПримерОписание
объект{ ключ: значение }Неупорядоченный набор пар
массив[1, 2, 3]Упорядоченный список
строка"текст"Строка в двойных кавычках
число42, 3.14Целое или дробное число
булевоистина, ложьЛогические значения
пустопустоОтсутствие значения
дата2024-01-15Дата в формате YYYY-MM-DD
длительность5д12ч30минПродолжительность

Ключи могут быть строками или идентификаторами (в том числе на кириллице).

#Комментарии

  • Однострочные: // комментарий
  • Многострочные: /* комментарий */

#Возможности расширения

  • ✅ Подсветка синтаксиса — грамматика Tree-sitter с подсветкой строк, чисел, -дат, длительностей, комментариев, пунктуации
  • ✅ LSP-интеграция — поддержка языкового сервера uon-lsp (должен быть установлен отдельно)
  • ✅ Автоматическое определение — файлы с расширениями .уон / .uon

#Установка

#Через Zed Extensions

  1. Откройте Zed
  2. Перейдите в Extensions (палитра команд: extensions: install extension)
  3. Найдите УОН
  4. Нажмите Install

#Вручную

  1. Клонируйте репозиторий: 
    git clone https://github.com/MiCkEyZzZ/uon-zed.git
  2. Соберите расширение: 
    cargo build --release --target wasm32-wasi
  3. Скопируйте полученный target/wasm32-wasi/release/uon-zed.wasm в директорию расширений Zed.

#Требования

  • Zed (версия с поддержкой WASM-расширений)
  • uon-lsp — языковой сервер (опционально, для LSP-функций)

Установка LSP:

cargo install --path uon-lsp
