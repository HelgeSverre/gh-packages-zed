#Arc Dark Theme for Zed

A dark theme for Zed based on the IntelliJ Arc Dark Theme by Pavel Zlámal.

HeaderHeader

#Manual Installation

  1. Copy arc-dark.json to your Zed themes directory:
mkdir -p ~/.config/zed/themes
cp themes/arc-dark.json ~/.config/zed/themes/

  1. Open Zed settings (Cmd+, on macOS, Ctrl+, on Linux)

  2. Select "Arc Dark" from the theme selector, or add to your settings:

{
  "theme": "Arc Dark"
}

#Color Palette

  • Backgrounds: #383c4a, #404651, #474c5b
  • Borders: #2b2e39
  • Accent/Focus: #2679db (Arc blue)
  • Text: #d3dae3, #ffffff
  • Muted: #9ba2ab
  • Keywords: #ffa833 (orange)
  • Strings: #c6ffa8 (green)
  • Comments: #a9a9a9 (gray)
  • Functions: #ffcf69 (yellow)
  • Types: #a8ebff (cyan)
