#Wiro AI MCP Server for Zed

Use Wiro AI from Zed's Agent Panel: search 1,000+ image, video, audio and LLM models, check their prices and run them, build and run workflows, and talk to Studio and your own agents.

Website · Models · MCP docs · Dashboard

This Zed extension adds the official Wiro AI MCP server to Zed. Zed downloads the server, @wiro-ai/wiro-mcp, from npm and runs it with the Node.js runtime it manages itself, so there is nothing else to install. Each time the server starts, the extension checks npm for a newer version.

#Install

  1. In Zed, open the command palette, run zed: extensions, search for Wiro AI MCP Server and click Install. You can also open Settings → AI → MCP Servers, click Add Server and choose Install from Extensions.
  2. Zed opens a configuration window. Put your project's API key in wiro_api_key, and its API secret in wiro_api_secret if the project uses signature-based authentication. Then click Configure Server.
  3. In Settings → AI → MCP Servers, the dot next to Wiro AI turns green when the server is running. If it does not, its tooltip says why, and zed: open log shows more detail.

#Get an API key

Sign up at wiro.ai and create a project at wiro.ai/panel/project/new. Your projects and their keys are listed at wiro.ai/panel/project.

You choose the authentication type when you create the project:

  • Signature-based: set both wiro_api_key and wiro_api_secret.
  • API Key Only: set wiro_api_key and leave wiro_api_secret empty.

#Settings

The configuration window saves your settings in Zed's settings.json. To change them later, run zed: open settings file and edit the mcp-server-wiro entry:

{
  "context_servers": {
    "mcp-server-wiro": {
      "settings": {
        "wiro_api_key": "your-api-key",
        "wiro_api_secret": "your-api-secret",
        "toolsets": ["models", "workflows"]
      }
    }
  }
}
SettingRequiredDescription
wiro_api_keyYesAPI key of your Wiro AI project
wiro_api_secretFor signature-based projectsAPI secret of the same project
toolsetsNoTool groups to load: any of models, workflows and agents. All groups load when it is left out

#Tools

With all groups loaded, the server gives the Agent Panel 50 tools:

workflows also loads the model tools a workflow needs: search_models, get_model_schema, recommend_model and upload_file. What each tool does is described in the Wiro MCP server README. The server also offers four MCP prompts: build_workflow, deploy_agent, create_with_studio and talk_to_my_agent.

#Try it

Open the Agent Panel and ask, for example:

  • "Find three text-to-image models on Wiro AI and compare their prices"
  • "Show me the parameters for google/veo3-1"
  • "Generate a photorealistic image of a mountain lake at sunset"
  • "Build a workflow that turns a product photo into a short ad video"
  • "Which agent templates can manage Instagram? What does each plan cost?"

Searching models and reading their parameters and prices is free. Running a model or a workflow, and messages to Studio or the Workflow Agent, are charged to the project's wallet. Messages to your own agents use the agent's credits. Tools with a known price, such as deploying an agent or buying credits, show the price first and act only after you confirm. Zed also asks you to approve each tool call unless you change its tool permissions.

#Hosted server

Zed can also connect to the hosted Wiro AI MCP server at https://mcp.wiro.ai/v1 without this extension: add it as a remote server in Settings → AI → MCP Servers and sign in with your Wiro AI account when Zed asks. See the MCP docs for details.

#Development

  1. Install Rust with rustup.
  2. Clone this repository.
  3. In Zed, run zed: install dev extension and pick the cloned folder.

cargo test runs the unit tests.
