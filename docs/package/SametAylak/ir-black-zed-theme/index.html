#IR Black Theme for Zed

A dark theme for Zed inspired by the classic IR_Black theme, featuring a pure black background with vibrant syntax highlighting colors.

#Installation

#Via Zed Extensions

  1. Open Zed
  2. Open the command palette (Cmd+Shift+P / Ctrl+Shift+P)
  3. Search for "zed: extensions"
  4. Search for "IR Black"
  5. Click Install
