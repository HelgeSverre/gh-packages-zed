#Pierre Icons for Zed

Unofficial. This is a community port. It isn't affiliated with or endorsed by The Pierre Computer Company, which designed the icons.

Pierre's file icons from @pierre/trees (the "complete" set, the one Claude Desktop's file tree uses), as a Zed icon theme.

Themes: Pierre Dark, Pierre Light (coloured) and Pierre Mono Dark/Light.

#Pierre Dark / Light

#Pierre Mono Dark / Mono Light

Icons are layered; an earlier layer wins whenever two cover the same file:

  1. @pierre/trees: the full "complete" set, with its colours and file mappings.
  2. Claude Desktop's changes: markdown as a green text document, plus PDF (red), Word (blue) and Slides (orange) icons and more spreadsheet types.
  3. @pierre/vscode-icons: everything the first two don't cover. That includes C#, Objective-C and the npm files, folder icons, and extra mappings for its otherwise-unused icons:
    • layers: design files (.psd, .fig, .sketch)
    • rss: .rss, .atom
    • gear: config files (.toml, .plist, Makefile)
    • code-block: markup (.xml, .proto, templates)
    • code: other languages (Java, Kotlin, PHP, Lua and more)
    • extension: .vsix, .crx
    • server: .http, Procfile

Because Zed matches file names case-sensitively, common spellings are added too (README.md, Dockerfile).

#Install (dev extension)

  1. In Zed: cmd-shift-p → zed: install dev extension → pick this folder.
  2. cmd-shift-p → icon theme selector: toggle → choose Pierre Dark (or Light).

To follow the system appearance, in settings.json:

"icon_theme": { "mode": "system", "light": "Pierre Light", "dark": "Pierre Dark" }

After rebuilding, run zed: reload extensions.

#Rebuild

pnpm install
pnpm build

Everything in icons/ and icon_themes/ is generated by scripts/build.mjs. pnpm build also writes preview.html and preview-detail.html (git-ignored) for checking the icons locally. pnpm screenshot re-renders the README images in docs/ (needs Google Chrome). pnpm test-files writes test-files/ (git-ignored), one folder per icon with a sample of every mapped file type, to check in Zed with zed test-files. Add your own mappings in layer 3 of the script.
