# Nightshade

An opinionated dark theme for [Zed](https://zed.dev) inspired by Synthwave aesthetics with the taste of how I like my editor.

## Features

- Deep black backgrounds with neon syntax highlighting
- Neon cyan functions, green tags, yellow keywords, pink properties, red types
- First-class syntax support for Rust (macros, lifetimes), TypeScript (decorators), and Python (decorators, builtins)
- Full terminal ANSI color support

## Installation

### Local Development

1. Clone this repository
2. In Zed, open `Extensions` and click "Install Dev Extension"
3. Select the `nightshade` directory

### Manual

Copy the `nightshade` folder to `~/.local/share/zed/extensions/` (Linux) or `~/Library/Application Support/Zed/extensions/` (macOS).
