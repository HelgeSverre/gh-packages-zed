# Nordppuccin for Zed

A clean, hybrid theme for [Zed](https://zed.dev) combining the cold, icy interface aesthetic of **Nord** with the warm pastel syntax highlighting of **Catppuccin**.

## Themes Included

Nordppuccin comes with two distinct variants designed for comfort during long coding sessions:

* **Nordppuccin Dark**: Features a deep, ultra-dark Nord-inspired background UI with Catppuccin Mocha syntax highlighting.
* **Nordppuccin Light**: Features a crisp Nord *Snow Storm* background UI with Catppuccin Latte syntax highlighting.

## Installation

### Dev Extension (Local)

1. Clone or download this repository:
   ```bash
   git clone https://github.com/franqong/nordppuccin-zed.git
   ```

2. Open **Zed**.
3. Open the Command Palette (`Cmd+Shift+P` on macOS / `Ctrl+Shift+P` on Linux/Windows).
4. Run `zed: install dev extension`.
5. Select the `nordppuccin-zed` folder.
6. Open the Theme Selector (`Cmd+K Cmd+T` or `Ctrl+K Ctrl+T`) and select **Nordppuccin Dark** or **Nordppuccin Light**.
