# Osaka Jade — Zed Theme

A jade-inspired theme for [Zed](https://zed.dev), ported from the [Osaka Jade](https://github.com/basecamp/omarchy/tree/master/themes/osaka-jade) theme by Justin Lowry (Omarchy / 37signals).

## Variants

| Variant              | Appearance | Background | Foreground |
| -------------------- | ---------- | ---------- | ---------- |
| **Osaka Jade Dark**  | Dark       | `#111c18`  | `#C1C497`  |
| **Osaka Jade Soft**  | Dark       | `#1b2f23`  | `#c9c8a0`  |
| **Osaka Jade Muted** | Dark       | `#273f30`  | `#d0cfac`  |
| **Osaka Jade Light** | Light      | `#edead4`  | `#2d4a35`  |

- **Dark** — the original Osaka Jade palette. Deep forest green background, warm olive foreground. High contrast.
- **Soft** — lifted background, mellowed saturation. Same green-teal identity with less eye strain.
- **Muted** — pastel-warm, low contrast. Comfortable for long sessions.
- **Light** — warm cream background with dark olive text. Full inversion of the Osaka Jade identity.

## Installation

Search for **Osaka Jade** in Zed's extension panel (`Cmd+Shift+X`), or install via the command palette:

```
zed: install extension osaka-jade-theme
```

Then open the theme selector (`Cmd+Shift+P` → `theme selector: toggle`) and pick your variant.

## Terminal Colors

All variants include the full 16-color ANSI palette (normal, bright, and dim) tuned to match the Osaka Jade identity. The terminal inside Zed will match your editor theme.
