# FreshJuice Themes for Zed

Fruit-named dark themes for the [Zed editor](https://zed.dev/).

## Themes

### FreshJuice: Cyber Banana

Deep warm-black with neon yellow accents. High contrast, amber syntax palette.

### FreshJuice: Cyber Banana High Contrast

Pure black background, maximized text contrast, boosted syntax colors.

## Installation

### From Zed

1. Open Zed
2. `Cmd+Shift+P` → Extensions: Install Extensions
3. Search "FreshJuice"
4. Click Install

### Manual

```bash
git clone https://github.com/freshjuice-dev/zed-themes.git \
  ~/.config/zed/extensions/freshjuice-themes
```
