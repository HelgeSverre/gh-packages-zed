# Midnight Theme for Zed

A dark theme for [Zed](https://zed.dev) featuring a refined charcoal background with subtle navy blue elements.

## Themes Included

- **Midnight Ash**: Charcoal dark theme with navy blue accents and balanced syntax highlighting.

## Installation

### From the Zed Extension Registry (Marketplace)

1. Open Zed.
2. Open the Extensions manager (`cmd-shift-x` or `ctrl-shift-x`, or `zed: extensions`).
3. Search for **Midnight**.
4. Click **Install**.

### Manual / Local Development

1. Clone or download this repository.
2. In Zed, run the command palette (`ctrl-shift-p` / `cmd-shift-p`).
3. Select `zed: install dev extension`.
4. Choose this directory.
