# Doom One Theme for Zed

A faithful and vibrant port of the popular **Doom One** theme from Doom Emacs to Zed.

This theme features 3 variations:
- **Doom One** (Default Dark): The classic Doom One flavor.
- **Doom One Darker**: A deeper and darker background with the same accents.
- **Doom One Light**: A light flavor based on `doom-one-light-theme.el`.

## Installation

Once installed, you can select these themes in your settings or using the theme selector (`ctrl-k ctrl-t` or `cmd-k cmd-t` on macOS).
