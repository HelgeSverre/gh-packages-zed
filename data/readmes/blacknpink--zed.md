# Black & Pink — Zed Theme

Minimalist, high-contrast Zed theme. Black backgrounds, soft pink accents, desaturated semantic colors. Part of the [Black & Pink](https://github.com/blacknpink) design system.

## Palette

- Backgrounds rise gradually: `#000000` → `#0a0a0a` → `#111111` → `#1a1a1a` → `#222222`
- Accent: `#ff4ead` (pink), used sparingly
- Text: `#f0f2f7` heading / `#d0d6e0` body / `#a0aabe` muted / `#4a4f5e` disabled
- Semantic: `#4ade80` success, `#facc15` warning, `#f87171` error, `#60a5fa` info, `#a78bfa` hint

See [`resources/stylesheet.md`](https://github.com/blacknpink/resources/blob/main/stylesheet.md) for the canonical reference.

## Install

### From the Zed extension store

Open the command palette → `zed: extensions` → search for **Black & Pink**.

### As a dev extension

1. Clone this repository.
2. In Zed, open the command palette → `zed: install dev extension` and select the cloned directory.
3. Open the theme selector (`theme selector: toggle`) and pick **Black & Pink**.
