# Dusty

Like an old friend. A muted navy theme for [Zed](https://zed.dev) with bright accents.

![Dusty theme — TypeScript](assets/screenshot2.png)

![Dusty theme — Search](assets/screenshot3.png)

## Install

1. Open Zed
2. Open the Extensions panel (`cmd+shift+x` or **Zed > Extensions**)
3. Search for **Dusty**
4. Click **Install**
5. Open your settings (`cmd+,`) and set the theme:

```json
{
  "theme": "Dusty"
}
```

Or use the theme switcher: `cmd+k cmd+t` and select **Dusty**.

## Manual Install

Clone this repo into your Zed extensions directory:

```sh
git clone https://github.com/claylo/dusty-zed.git \
  ~/.local/share/zed/extensions/installed/dusty
```

Restart Zed and select **Dusty** from the theme switcher.
