# Gruvbox Baby Zed Port

Zed port of the gorgeous [Gruvbox Baby](https://github.com/luisiacc/gruvbox-baby) theme.

Background has been darkened to `#141617`.

![gruvbox-baby](./screenshots/gruvbox-baby-zed.png)

- **Font**: [Adwaita Mono](https://gitlab.gnome.org/GNOME/adwaita-fonts) ([nerd font version](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/AdwaitaMono#option-1-download-already-patched-font))
- **Icons**: [Material Icon Theme](https://github.com/zed-extensions/material-icon-theme)

## Color Palette

- **Background**: #141617 (Custom dark)
- **Foreground**: #ebdbb2 (Warm white)
- **Comments**: #665c54 (Muted brown)
- **Keywords**: #fb4934 (Soft red)
- **Functions**: #eebd35 (Warm yellow)
- **Strings**: #98971a (Soft green)
- **Types**: #8ec07c (Clean green)
- **Variables**: #7fa2ac (Light blue)

## Installation

1. Clone or download this extension
2. Place the json in `~/.config/zed/themes`
4. Select "Gruvbox Baby" from the theme picker with Ctrl+k Ctrl + t
