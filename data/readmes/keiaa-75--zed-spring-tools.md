# Spring Tools for Zed

Spring language support for [Zed](https://zed.dev) via the [Spring Tools 4](https://spring.io/tools) language server.

## Work in progress

- [ ] Workspace and argument configuration
- [ ] Additional initialization options
- [ ] Tasks and runners (Maven, Gradle)

## Requirements

- JDK 17 or later installed and available on your `PATH`
- A Java extension for Zed (for base Java language support)

## Install as a Dev Extension

Clone the repository:
```bash
git clone https://github.com/keiaa-75/zed-spring-tools/
```

1. Make sure you have Rust installed through `rustup`.
2. Open the command palette or the extensions panel.
3. Select `zed: install dev extension`.
4. Select the folder containing the source code.

The language server is downloaded automatically on first use.
