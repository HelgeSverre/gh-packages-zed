# Summercamp for Zed

Summercamp started life as one of the earliest Zed themes, was recreated by hand as a [VS Code theme](https://github.com/csalmeida/summercamp-vscode-theme), and has now come full circle — recreated as a Zed extension after the original was no longer available from Zed's built-in themes.

![Summercamp theme in Zed](screenshots/summercamp_dark.png)

## Installation

Once published, install it from Zed via `zed: extensions` and search for "Summercamp".

### Local development

1. Clone this repository.
2. In Zed, run `zed: install dev extension` from the command palette and select the repository folder.
3. Select the theme via `theme selector: toggle`.

Alternatively, copy `themes/summercamp.json` into `~/.config/zed/themes/` to use it without installing the extension.
