# Paper Pastel Theme Pack

A soft pastel theme pack for Zed designed for long coding sessions.

## Themes

• Paper Pastel Lite — light theme  
• Paper Pastel Dark — balanced dark theme  
• Paper Pastel Midnight — deep dark theme for night coding

## Features

- soft pastel palette
- low eye strain
- balanced contrast
- clean diff colors
- optimized syntax for Python, JSON and Markdown

## Installation

1. Download the repository
2. Copy the theme JSON files into:

~/.config/zed/themes/

3. Restart Zed and select the theme.
