# macOS Prism

A macOS-inspired Zed color theme with rich, colorful syntax highlighting for dark and light modes.

## Installation

**From the Zed Extension Store:**

1. Open Zed and press `Cmd+Shift+X` (or go to **Zed → Extensions**)
2. Search for "macOS Prism"
3. Click **Install**

**From source:**

1. Clone this repo
2. In Zed, open the Command Palette (`Cmd+Shift+P`)
3. Run **zed: install dev extension**
4. Select the cloned directory

## Activating the theme

Press `Cmd+K Cmd+T` to open the theme selector and pick **macOS Prism**. Set it to follow your system appearance by choosing the dynamic option — it'll switch between light and dark automatically.
