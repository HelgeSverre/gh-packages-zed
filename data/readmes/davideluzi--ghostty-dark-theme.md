# Ghostty Dark Theme for Zed

Theme inspired on Ghostty terminal emulator dark theme for [Zed](https://zed.dev).

A dark theme with fresh pleasant colors and a good contrast, tot too dark nor faded. Ideal for PHP.

## Install

Copy the `themes/*.json` files from this repo into `~/.config/zed/themes`.

Then select your theme via Settings -> Select Theme.
