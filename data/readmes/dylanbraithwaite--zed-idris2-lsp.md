# Idris 2 LSP support for the Zed editor.

Currently very barebones Zed extension for Idris 2 language support.
- Uses the Idris 2 treesitter grammar from https://github.com/kayhide/tree-sitter-idris
- Expects the [Idris 2 lsp server](https://github.com/idris-community/idris2-lsp) to be installed and available in the PATH as `idris2-lsp`
