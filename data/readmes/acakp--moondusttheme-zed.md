# Moondust Theme for Zed

A theme for the [Zed Editor](https://zed.dev/), for those who have not found syntax highlighting useful for themself.

> **Note:** This is a modified port of [vanyauhalin's moondusttheme](https://github.com/vanyauhalin/moondusttheme).

![Showcase of the light variant](dark.png)

![Showcase of the dark variant](light.png)

## Installation

1. Clone this repository to your local machine
2. Open the Extensions panel in Zed, click "Install Dev Extension" and select the cloned repository folder
