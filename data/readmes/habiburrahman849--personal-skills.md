## Why This Repository Exists

Most people get generic, robotic answers from AI because they don't give the AI a structured workflow or their personal identity.

This repository solves that with **11 battle-tested AI Skills**. Every single skill folder includes:
1. **`SKILL.md`** — The complete step-by-step expert system prompt and execution rules for the AI agent.
2. **`instructions/user-profile.md`** — **Your Mandatory Personal Instruction File.** You simply open this file and enter your **Name, Brand Name, Brand Colors, Tone of Voice, Skills, and Links** once. The AI agent reads your `instructions/user-profile.md` first and automatically personalizes every output for **you**!

## How to Use With Any AI Platform (Step-by-Step)

### Step 1: Customize Your `instructions/user-profile.md`
Open the `instructions/user-profile.md` file inside the skill folder you want to use and replace the placeholders with your own details:
- **Your Name**
- **Your Brand / Channel / Store Name**
- **Your Brand Colors & Visual Style**
- **Your Tone of Voice & Preferred Language (Roman Urdu / Urdu / English)**
- **Your Website, Portfolio, GitHub, Store, or Social Links**

### Step 2: Plug Into Your Favorite AI

#### Option A: Claude (Claude Projects / Claude Desktop / Claude Code)
1. Create a new **Claude Project** (or open a chat).
2. Upload both `SKILL.md` and `instructions/user-profile.md` from the skill folder into **Project Knowledge** (or paste `SKILL.md` into Custom Instructions).
3. Type your topic, product, or job post—Claude will automatically follow the skill and your personal profile.

#### Option B: ChatGPT (Projects / Custom GPTs / Normal Chat)
1. Create a **ChatGPT Project** or **Custom GPT**.
2. Paste the contents of `SKILL.md` into **Instructions** and upload `instructions/user-profile.md` as a knowledge file (or attach both files in any chat).

#### Option C: Perplexity (Spaces) & Grok (Workspaces)
1. Create a **Space** in Perplexity (best for Skill 02 Deep Research & Skill 05 Trending Product Hunter) or a **Workspace** in Grok.
2. Add `SKILL.md` as the System Prompt and upload `instructions/user-profile.md`.

#### Option D: Zed Editor / Cursor / Agentic Coding Tools
1. Clone this repository or copy the skill folders into `~/.agents/skills/` (Global) or `.agents/skills/` (Project-local):
   ```bash
   git clone https://github.com/habiburrahman849/personal-skills.git
   ```
2. Invoke any skill directly using the `/` slash command or let the agent load it automatically.
