# Afterglow Remastered for Zed

A port of the [Afterglow Remastered](https://github.com/marvinhagemeister/vscode-theme-afterglow-remastered)
theme for VS Code by Marvin Hagemeister to the [Zed](https://zed.dev) editor —
which is itself a remaster of the classic
[Afterglow theme for Sublime Text](https://github.com/YabataDesign/afterglow-theme)
by YabataDesign.

A warm, muted dark theme: orange keywords, yellow functions, green strings,
blue constants and white type names on a soft `#2e2e2e` background.

![Afterglow Remastered in Zed](preview.jpg)

## Installation

### From the extension gallery

Once published, open Zed's extension panel (`zed: extensions` in the command
palette) and search for **Afterglow Remastered**.

### As a dev extension

1. Clone this repository.
2. In Zed, open the command palette and run `zed: install dev extension`.
3. Select the cloned directory.
4. Choose **Afterglow Remastered** via `theme selector: toggle`.
