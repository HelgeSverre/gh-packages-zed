# The Forbidden One

A dark-only theme for [Zed](https://zed.dev) by **Kyoka-Suigetsu**.

## Variants

- **The Forbidden One Dark** — near-black surfaces with teal details.
- **The Forbidden One Blue** — deep indigo-blue surfaces.
- **The Forbidden One Purple** — deep violet surfaces.
- **The Forbidden One Teal** — deep teal surfaces.

Each variant styles Zed's interface, editor, syntax highlighting, diagnostics,
Git Graph, and integrated terminal. All four variants share a colorful Git
Graph palette while keeping their own backgrounds, text, and syntax colors.
