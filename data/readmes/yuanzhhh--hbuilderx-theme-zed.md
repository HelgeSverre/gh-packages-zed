# HBuilderX Push Light Theme for Zed

A light theme for Zed editor inspired by HBuilderX with soothing green accents.

## Features

- Light color scheme optimized for coding
- Green accent colors for focus elements
- Carefully selected syntax highlighting colors
- Consistent UI colors throughout the editor

## Installation

### From Zed Extensions Marketplace

1. Open Zed editor
2. Open the command palette (`Cmd+Shift+P` on macOS, `Ctrl+Shift+P` on Windows/Linux)
3. Search for "HBuilderX Push Light" and install the extension
4. Select the theme from the theme selector

### Manual Installation

1. Download the `hbuilderx-push-light.json` theme file from the [latest release](https://github.com/yuanzhhh/hbuilderx-theme-zed/releases/latest)
2. Create a `themes` directory in your Zed config folder (typically `~/.config/zed/`)
3. Copy the theme file to the `themes` directory
4. Restart Zed and select "HBuilderX Push Light" from the theme selector

## Color Palette

The theme uses a warm light background with green accents:

- **Background**: `#fffae8` (warm light)
- **Text**: `#404b53` (dark gray)
- **Accent**: `#41a863` (green)
- **Border**: `#d8ca9e` (light brown)
- **Selection**: `#e0edd3` (light green)

## Development

To modify the theme:

1. Clone this repository
2. Edit `themes/hbuilderx-push-light.json`
3. Test the theme by installing it locally
