# Mire Theme

![Mire theme preview](assets/mire-preview.png)

A warm, minimal Zed theme family with deep black and soft ivory variants, pairing quiet UI surfaces with refined orange, gold, teal, cream, and rose syntax accents.


## Themes included

- Mire Afterdark
- Mire Afterlight

## Recommendations
Add the following line to your Zed settings config:

```json
{
  "semantic_tokens": "combined",
}
```

## Local development install

1. Open Zed.
2. Open Extensions with `cmd-shift-x` on macOS or `ctrl-shift-x` on Linux/Windows.
3. Click **Install Dev Extension**, or run `zed: install dev extension` from the command palette.
4. Select this repository folder, the one containing `extension.toml`.
5. Open the theme selector with `cmd-k cmd-t` / `ctrl-k ctrl-t` and select a Mire variant.

## Development

Theme styles live in `themes/mire.json`. After editing theme values, reload the dev extension in Zed if changes do not appear immediately.
