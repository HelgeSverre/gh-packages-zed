# Voidline

Voidline is a five-variant theme family for Zed. It uses carbon-black surfaces, restrained text contrast, and focused syntax colors designed for long coding sessions.

## Variants

- **Voidline Slate** is the opaque carbon-black daily driver.
- **Voidline Glass** adds native blurred transparency while preserving code readability.
- **Voidline Signal** uses stronger color separation for fast scanning.
- **Voidline Dusk** softens contrast for low-light environments.
- **Voidline Dawn** carries the palette into a light theme.

## Install locally

Copy `themes/voidline.json` into `~/.config/zed/themes/`, then choose a Voidline variant from Zed's theme selector.
