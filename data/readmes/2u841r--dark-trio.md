# Dark Trio

3 dark themes for [Zed](https://zed.dev) editor.

## Themes

### Bytes Newsletter Colorized+
Dark theme based on the [Bytes](https://bytes.dev) newsletter aesthetic. GitHub-dark background with a colorful syntax palette.

### Svelte 5
Dark theme built for Svelte development. Muted background with blue keywords and warm orange-peach for functions and tags.

### Pinky Promise
Dark theme with a pink and lavender palette. Deep purple-black background with pink keywords, lavender functions, and mint strings.

## Install

Search **Dark Trio** in Zed Extensions (`zed: extensions`), or install via CLI:

```
zed --install-extension dark-trio-themes
```
