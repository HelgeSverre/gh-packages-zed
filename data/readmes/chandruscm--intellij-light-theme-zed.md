# IntelliJ Light Theme for Zed

For those of us who unapologetically use light themes. Rarely spotted, often mocked, but never extinct!

This light theme for Zed replicates the default light theme that comes standard with IntelliJ IDEA / Android Studio.

![dub](./screenshots/dub.png)

## Installation

1. Clone this repository
2. In Zed, open the command palette (Cmd+Shift+P) / (Ctrl+Shift+P)
3. Run `zed: install dev extension`
4. Select the cloned folder

## Installing JetBrains Mono

JetBrains Mono is the default font that comes standard with IntelliJ IDEA / Android Studio. Download it from:
- [JetBrains Mono Official Site](https://www.jetbrains.com/lp/mono/)
- [Google Fonts](https://fonts.google.com/specimen/JetBrains+Mono)

After installing the font, set the font in your Zed settings.json:

```json
  "buffer_font_family": "JetBrains Mono",
  "buffer_font_weight": 300, // Optional
```
