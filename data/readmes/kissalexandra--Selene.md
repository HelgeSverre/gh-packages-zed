## Installation
### Ghostty
1. Copy [Selene](https://github.com/camieeh/Selene/blob/main/Ghostty/Selene) or [Selene-Blur](https://github.com/camieeh/Selene/blob/main/Ghostty/Selene-Blur) into `~/.config/ghostty/themes/`
2. Add `theme = Selene` or `theme = Selene-Blur` to your Ghostty configuration
3. Optional: Apply other [recommended visual settings](https://github.com/camieeh/Selene/blob/main/Ghostty/config) in Ghostty's config
4. Quit and relaunch Ghostty

### Xcode
1. Copy [Selene.xcworkspacecolortheme](https://github.com/camieeh/Selene/blob/main/Xcode/Selene.xcworkspacecolortheme) into `~/Library/Developer/Xcode/UserData/FontAndColorThemes` or import it directly in Xcode's `Appearance` settings
2. Restart Xcode if you copied the file instead of importing it
3. Select `Selene` under `Xcode > Settings... > Appearance > Theme > Choose`

### Zed
1. Copy [Selene.json](https://github.com/camieeh/Selene/blob/main/Zed/Selene.json) into `~/.config/zed/themes/`
2. Select `Selene` under `Zed > Settings > Select Theme...`
3. Optional: Install `Colored Zed Icons Theme` from the Zed extension store for colored file icons
