# Sukun - سكون

![Sukun](screenshots/hero.png)

A calm, warm theme for [Zed](https://zed.dev).

Sukun (سكون — "stillness") ships four variants:

- **Sukun** — light
- **Sukun Soft** — light, lower contrast
- **Sukun Dark** — dark
- **Sukun Soft Dark** — dark, lower contrast

## Install

### From the Zed extensions panel

Open the command palette → `zed: extensions`, search for **Sukun**, and install.

### Local development

1. Clone this repo.
2. Open the command palette → `zed: install dev extension`.
3. Select this directory.

Then pick a variant via the command palette → `theme selector: toggle`.
