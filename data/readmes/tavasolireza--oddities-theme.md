# Oddities: Uncommon Themes

Some themes for [Zed](https://zed.dev) with uncommon color combinations that I like.

![Oddities theme previews](assets/oddities-preview.png)

## Included themes

- **Soft2000 Light** and **Soft2000 Dark** — Zed ports of the original Soft2000 themes, including their deliberately low contrast.
- **Golden Eye Refined** — a Zed port with small readability adjustments.
- **Yuuyake Refined** — a Zed port that uses normal text instead of the original theme's italic styling.

## Install

1. Open Zed's Extensions view (`zed: extensions` in the command palette).
2. Search for **Oddities: Uncommon Themes**.
3. Install the extension, then select one of the included themes with `theme selector: toggle`.

Until the extension is accepted into Zed's registry, clone this repository and use `zed: install dev extension`, selecting the repository directory.
