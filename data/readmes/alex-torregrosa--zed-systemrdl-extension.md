# Zed SystemRDL extension

Zed extextension to support the [SystemRDL 2.0](http://accellera.org/downloads/standards/systemrdl) register description language. Based on the [official tree-sitter grammar](https://github.com/SystemRDL/tree-sitter-systemrdl).

## Implemented queries

* Syntax highlighting
* Outline
* Bracket matching
* Auto-indentation
