# CCLS support for Zed Editor

[CCLS](https://github.com/MaskRay/ccls) is an alternative language server to Clangd.

## Usage

1. Clone this repository.
2. Open Zed
3. Open the extensions page.
4. Hit "Install Dev Extension".
5. Navigate to this directory. (You will need rustc)

CCLS must be installed and available in PATH. This extension does not
automatically download it for you, as CCLS does not distribute any precompiled
binaries.

You should also disable the built-in clangd LSP. This can be done by adding the
following to your workspace or global settings:

```json
{
    "languages": {
        "C++": {
            "language_servers": ["ccls", "!clangd", "..."]
        },
        "C": {
            "language_servers": ["ccls", "!clangd", "..."]
        }
    }
}
```

In the above, the CCLS LSP is enabled, clangd is disabled, while leaving all
other LSPs enabled (if you have others).

## Why CCLS?

For embedded work with `platformio`, a `.ccls` can be autogenerated for you via:

```text
platformio project init --ide vim
```

This will give CCLS all the required include directories and compile flags. A
root `compile_commands.json` file can also be generated via
`pio run -t compiledb`. By running these two commands, you can have a pretty
good experience writing your embedded code.
