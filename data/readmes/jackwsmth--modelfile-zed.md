# Modelfile Zed Extension

This is a Zed extension for [Ollama](https://ollama.com)'s Modelfile syntax.

This makes use of [tree-sitter-modelfile](https://github.com/jackwsmth/tree-sitter-modelfile) for the grammar. 

# Functionality

The scope of this extension currently is to provide syntax highlighting for Modelfiles. 

There is no configuration required.
