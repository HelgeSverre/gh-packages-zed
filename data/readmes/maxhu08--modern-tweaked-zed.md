# VSCode Modern Tweaked

VSCode Modern Tweaked builds on the VS Code Modern themes for Zed, refining colors and contrast to make them cleaner, more polished, and more comfortable for everyday coding.

## Showcase

[View showcase of themes](SHOWCASE.md)

## Included themes

- `VSCode Dark Modern Tweaked`
- `VSCode Darker Modern Tweaked`
- `VSCode Light Modern Tweaked`

## Install locally

1. Open Zed's command palette.
2. Run `zed: install dev extension`.
3. Select this repository's root directory.
4. Open the theme selector and choose one of the themes above.
