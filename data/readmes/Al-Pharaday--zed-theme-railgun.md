## Manual Installation
- Download the theme .json file.
- Copy it to the `~/.config/zed/themes/` directory (or `%USERPROFILE%\AppData\Roaming\Zed\themes\` on Windows).
- Open Zed, `Toggle User Menu` -> `Themes` -> Select the theme.
