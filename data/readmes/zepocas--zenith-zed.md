# Zenith for Zed

A warm dark theme with muted greys and Gruvbox-inspired syntax colours.

## Install

From the Zed extension store: open the Extensions panel (`ctrl-shift-x`), search for **Zenith**, and install it.

Then select it with `theme selector: toggle`, or set it in `settings.json`:

```json
"theme": {
  "mode": "dark",
  "dark": "Zenith",
  "light": "Gruvbox Light"
}
```

## Develop

1. Clone this repo.
2. In Zed, run `zed: install dev extension` and choose the cloned folder.
3. Edit `themes/zenith.json`. Zed reloads the theme when the file changes.
