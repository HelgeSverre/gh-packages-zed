# zed-ungrammar

[Ungrammar](https://github.com/rust-analyzer/ungrammar) (`.ungram` files) support for [Zed](https://zed.dev/) editor.

See [introducing blog post](https://rust-analyzer.github.io/blog/2020/10/24/introducing-ungrammar.html).

## Features

- Grammar syntax highlight ([tree-sitter-ungrammar](https://github.com/tree-sitter-grammars/tree-sitter-ungrammar))
- Language server ([ungrammar-languageserver](https://github.com/binhtddev/ungrammar-language-features))
