# Pointer — Cursor-inspired theme for Zed

A dark and light theme for [Zed](https://zed.dev/) with colors extracted directly from Cursor IDE's bundled theme files (`theme-cursor` extension).

## Installation

### From extensions (recommended)

1. Open Command Palette (`Cmd+Shift+P`)
2. Type `extensions`
3. Search for "Pointer" and install

### Manual

Copy `themes/pointer.json` to `~/.config/zed/themes/`, then select "Pointer Dark" or "Pointer Light" from the theme picker (`Cmd+K Cmd+T`).
