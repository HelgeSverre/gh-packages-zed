A minimal Vercel Geist-inspired theme for Zed: stark canvas, crisp hairlines, monochrome editor chrome, and focused syntax color drawn from Vercel's blue, violet, pink, cyan, and amber accents.

**Tags:** `zed`, `zed-theme`, `theme`, `dark-theme`, `light-theme`, `vercel`, `geist`, `editor-theme`, `developer-tools`

## Themes

- Vercel Light
- Vercel Dark

## Install Locally

1. Open Zed.
2. Run `zed: extensions` from the command palette.
3. Select `Install Dev Extension`.
4. Choose this repository folder.
5. Pick `Vercel Light` or `Vercel Dark` from Zed's theme selector.
