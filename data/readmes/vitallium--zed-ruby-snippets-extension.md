# Ruby Snippets for Zed

Ruby language snippets for Zed. The collection includes class, module, method,
enumerable, exception-handling, conditional, Minitest, and RSpec templates.

## Development

Install the repository from Zed's Extensions page using **Install Dev
Extension**, then select this repository's root folder. Open a Ruby file and
enter one of the snippet prefixes in the completion menu.

## Provenance

The snippets are derived from
[Shopify Ruby LSP](https://github.com/Shopify/ruby-lsp/blob/main/vscode/snippets.json).
They were incorporated into the
[Zed Ruby extension](https://github.com/zed-extensions/ruby) before being
extracted into this standalone extension and subsequently modified for Zed.
