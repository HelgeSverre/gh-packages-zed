# 42nd

Dark, quiet themes for VS Code and Zed.
Near-black backgrounds and a slate UI borrowed from Solitude, with just enough color to read code fast.

- **42nd**: the original palette, with purple keywords, blue strings, gold properties and red tags.
- **42nd Ember**: almost monochrome, with a single ember accent for what matters.
