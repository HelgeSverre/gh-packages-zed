# Token-themes

Token-themes is a Zed theme extension with light and dark variants:

- Token Light
- Token Dark

This is a Zed port of Thorsten Rhau's Token color scheme.

## Local Development

Install this repository as a dev extension from Zed:

1. Open the command palette.
2. Run `zed: install dev extension`.
3. Select this repository directory.
4. Choose `Token Light` or `Token Dark` from the theme selector.
