# Arch-chan for Zed

Dark blue theme for the [Zed](https://zed.dev) editor, inspired by Arch-chan fan art by @repriham.

![Arch-chan preview](screenshots/preview.png)

Palette: deep navy background, blue accent, purple keywords, teal types, pink variables.

## Install

Copy `themes/arch-chan.json` to `~/.config/zed/themes/`, then pick **Arch-chan** via `theme selector: toggle` (`ctrl+shift+p`).
