# Catppuccin Black Theme

Catppuccin, but with the lights actually off.

For a long time, there has been a very specific wish floating around among people who live in their editors: keep the soft, readable, pastel language of Catppuccin, but let the editor background be truly black. Not almost black. Not tastefully charcoal. Black.

Catppuccin Black is a Zed theme built around that idea. The editor and terminal sit on `#000000`, while the surrounding interface keeps enough depth, contrast, and Catppuccin color warmth to stay comfortable during long sessions.

## Why

Catppuccin already feels calm, familiar, and beautifully tuned. This theme keeps that spirit, then adapts it for people who prefer a true-black workspace:

- `#000000` editor and terminal backgrounds
- Catppuccin-inspired pastel syntax colors
- ANSI terminal colors adapted from a true-black Catppuccin palette
- Subtle panels, tabs, borders, search highlights, diagnostics, and Git states
- Designed for OLED displays, dark rooms, and focused late-night coding

## Installation

Once published, install it from Zed's Extensions view and select `Catppuccin Black` from the theme selector.

For local development:

1. Open the Zed command palette.
2. Run `zed: install dev extension`.
3. Select this repository.
4. Run `zed: reload extensions`.
5. Choose `Catppuccin Black` from `theme selector: toggle`.
