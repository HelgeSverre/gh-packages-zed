# Draw.io MCP for Zed

A Zed extension that exposes the official [draw.io MCP tool server](https://github.com/jgraph/drawio-mcp) (`@drawio/mcp`) as a context server, so Zed's AI assistant can open XML, CSV, and Mermaid diagrams directly in the draw.io editor.

No configuration required — install the extension and the assistant gains three tools: `open_drawio_xml`, `open_drawio_csv`, `open_drawio_mermaid`.
