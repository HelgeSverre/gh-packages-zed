# zed-apache-avro
Zed Extension for Apache Avro ([IDL](https://avro.apache.org/docs/1.12.0/idl-language/)).

It provides syntax highlight to `.avdl` files using
[tree-sitter-apache-avro](https://github.com/victorhqc/tree-sitter-apache-avro)
