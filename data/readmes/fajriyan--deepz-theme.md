## Installation

### From the Zed Extensions Marketplace

1. Open **Extensions** in Zed.
2. Search for **Deepz**.
3. Click **Install**.
4. Open **Settings → Theme** and select **Deepz**.

### Manual Installation

Clone this repository into your Zed extensions directory.

```bash
git clone https://github.com/fajriyan/deepz-theme.git
```
