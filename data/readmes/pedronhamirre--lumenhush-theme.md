# Lumenhush Theme

A calm dark theme for [Zed](https://zed.dev) with warm accents and low-contrast color separation for effortless code reading.

## Visual direction

- Near-black surfaces with subtle depth
- Warm peach focus and selection accents
- Muted pink, lilac, mint, and green syntax colors
- Clear semantic separation without visual noise

## Installation

Once published, install **Lumenhush Theme** from Zed's Extensions panel and select **Lumenhush** in the theme selector.
