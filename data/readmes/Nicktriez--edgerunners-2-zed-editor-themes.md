# Edgerunners 2 — Zed Editor Themes

A theme extension for the [Zed](https://zed.dev) editor, inspired by the characters of *Cyberpunk: Edgerunners*.

## Variants

| Theme | Mode | Palette |
|---|---|---|
| `Talia` | Dark | Warm pink/red with yellow accents |
| `Weak` | Dark | Green/teal with amber accents |
| `Roman` | Light | Steel blue with red accents |
| `D` | Dark | Navy blue with pink/cyan accents |

## Installation

1. Clone this repository locally.
2. Open Zed and run `zed: install dev extension` from the command palette.
3. Select the cloned repository folder.
4. Open the theme selector (command palette → `theme: select`) and choose a variant.
