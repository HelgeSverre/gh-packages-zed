# A Distant Hope

Theme for [Zed](https://zed.dev) based on [An Old Hope](https://github.com/jesseleite/an-old-hope-syntax-atom).

## Install From GitHub

1. Clone this repo `cd ~/.config/zed/themes/ && git clone https://github.com/chrislockard/a-distant-hope-theme`
2. In Zed, open command palette (e.g., cmd-shift-p) and run "zed: install dev extension" and enter `~/.config/zed/themes/a-distant-hope-theme` 
3. Open the command palette again and enter `theme selector: toggle` and choose `A Distant Hope`

I hope you enjoy the theme! PRs welcome!
