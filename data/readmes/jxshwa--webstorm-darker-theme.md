# WebStorm Darker Theme

A darker WebStorm-inspired theme for the **Zed editor**.

This theme recreates the familiar JetBrains / WebStorm Darcula syntax palette while using a deeper, darker UI background to reduce eye strain during long coding sessions.

## Features

- JetBrains **Darcula-style syntax colors**
- Darker editor and UI surfaces
- Consistent colors accross:
    - editor
    - terminal
    - UI elements
    - git changes
    - syntax highlighting

## Color Pallette Highlights

| Element       |   Color   |
| :------------ | :-------: |
| Keywords      | `#CC7832` |
| Strings       | `#6A8759` |
| Numbers       | `#6897BB` |
| Functions     | `#FFC66D` |
| Constants     | `#9876AA` |
| Tags/Selector | `#E8BF6A` |
| Comments      | `#808080` |

## Installation

You can install it by cloning the repository.

1. Clone this [repository](https://github.com/jxshwa/webstorm-darker-theme.git) to your local machine.
2. Open the Extensions panel in Zed, click "Install Dev Extension" and select the cloned repository folder.
