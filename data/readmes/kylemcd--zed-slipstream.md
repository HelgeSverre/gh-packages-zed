A dark and fast theme for [Zed](https://zed.dev).

## Color Palette

| Color | Hex | Used For |
| --- | --- | --- |
| Black | `#000000` | Background |
| Teal | `#5CB8A2` | Functions, tags, attributes |
| Gold | `#F4D58D` | Strings, numbers, constants |
| Sky | `#8CB8DC` | Keywords, types, enums |
| Rose | `#E85C6C` | Errors |

## Installation

### From Zed Extensions

1. Open Zed
2. Open the command palette (`Cmd+Shift+P`)
3. Search for "Extensions"
4. Search for "Slipstream"
5. Click Install

### Manual Installation

1. Clone this repository
2. Open Zed's settings and add the path to your themes directory
3. Select "Slipstream" from the theme picker
