# Godot MCP Server Extension for Zed

This extension integrates [Godot MCP](https://github.com/Coding-Solo/godot-mcp) as a context server for
[Zed's](https://zed.dev) [Agent Panel.](https://zed.dev/docs/ai/overview)

To install navigate to: **Zed** > **Extensions** and search for `Godot MCP`.

## Requirements

- [Godot Engine](https://godotengine.org/) installed on your system
- Node.js (>=18.0.0) and npm

## Configuration

No configuration is required. The extension will automatically download and run the latest Godot MCP server via npm.
