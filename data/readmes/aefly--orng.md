## Overview

Orng is a minimal, high-contrast theme for [Zed](https://zed.dev/) built around
a bold orange accent. It ships in matching dark and light variants,
designed to stay clean and distraction-free during long coding sessions.

## Install

### Via Zed Extensions

- Open Zed
- Open the command palette <kbd>Cmd+Shift+P / Ctrl+Shift+P</kbd>
- Run `zed: extensions`
- Search for `Orng` and click Install
- Open the command palette again and run `theme selector: toggle`
- Select `Orng Dark` or `Orng Light`

### Manually

- Clone this repository into your Zed extensions directory
- Open the command palette and run `zed: install dev extension`
- Select the cloned folder
