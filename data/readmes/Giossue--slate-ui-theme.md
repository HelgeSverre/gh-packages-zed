# Slate UI Theme

A minimal slate UI theme family with dark, light and mono dark variants.

## Included themes

- `Slate UI Dark`
- `Slate UI Light`
- `Slate UI Mono Dark`

## Local development

Install as a dev extension in Zed:

1. Open the command palette.
2. Run `zed: install dev extension`.
3. Select this directory.
4. Reload Zed and open the theme selector.
