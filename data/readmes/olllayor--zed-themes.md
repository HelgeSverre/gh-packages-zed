# Zed Themes

A monorepo of color themes crafted for [Zed](https://zed.dev).
Each directory is a standalone Zed extension with its own manifest and version.

| Extension | Directory | Themes |
| --------- | --------- | ------ |
| Pearl Theme | [pearl/](pearl/) | Pearl Light, Pearl Dark |
| Midnight Dark | [midnight/](midnight/) | Midnight Dark |

## Development / Local Install

1. Clone this repository:
   ```bash
   git clone https://github.com/olllayor/zed-themes.git
   ```
2. Open Zed and open the Command Palette (`cmd-shift-p`).
3. Run `zed: install dev extension` and select the `pearl/` or `midnight/` directory.
