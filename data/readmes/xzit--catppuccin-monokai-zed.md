# Catppuccin Monokai for Zed

A custom color theme for the Zed editor that blends the high-contrast logic of **Monokai** with the soothing **Catppuccin** palette.

## 🚀 Installation

### Install via Zed

1. Open Zed.
2. Open the command palette with `Ctrl+Shift+P` (or `Cmd+Shift+P` on macOS).
3. Type `zed: extensions`.
4. Search for **Catppuccin Monokai** and install the extension.

### Manual Installation

1. Clone this repository or download the theme JSON file.
2. Copy the JSON file into your Zed theme directory (typically `~/.config/zed/themes`).

## ⚙️ Activating the Theme

1. Open the command palette (`Ctrl+Shift+P` / `Cmd+Shift+P`).
2. Run `theme selector: toggle`.
3. Choose **Catppuccin Monokai** from the theme list.
