# Zed

Zed is a high-performance, open-source code editor built in Rust by the creators of Atom and Tree-sitter. It focuses on speed and collaboration, with built-in AI assistance, real-time multiplayer editing, and a GPU-accelerated UI.

### Key Features

- GPU-accelerated rendering for fast startup and smooth editing
- Built-in AI assistant with support for multiple LLM providers
- Real-time collaborative editing with shared workspaces
- Open-source and extensible with a growing extension ecosystem
