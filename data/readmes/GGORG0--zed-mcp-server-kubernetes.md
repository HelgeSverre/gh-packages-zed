# Kubernetes MCP Server extension for Zed Editor

This extension integrates the [Kubernetes MCP Server](https://github.com/containers/kubernetes-mcp-server/) with [Zed Editor's Agent](https://zed.dev/docs/ai/overview).

See more information in the [official server repo](https://github.com/containers/kubernetes-mcp-server/). This extension has no configuration options, as the server uses your system's kubeconfig file.
