# Catthode for Zed

> **From CRT to OLED.** Bringing warmth back to a world of cold themes. [cattho.de](https://cattho.de/)

A complete Catthode theme for Zed's interface, editor, syntax highlighting, terminal, diagnostics, version control, Vim modes, and collaboration cursors.

## Local installation

1. Clone this repository.
2. Open Zed's command palette.
3. Run **zed: install dev extension**.
4. Select the cloned repository directory.
5. Run **theme selector: toggle** and choose **Catthode**.

## Extension Gallery

Once published, open Zed's Extensions view, search for `Catthode`, and install it from the gallery.
