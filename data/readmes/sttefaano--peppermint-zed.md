# Peppermint for Zed

A dark theme for [Zed](https://zed.dev/) with colorful syntax highlighting on a pure black background.

## Credits

This theme is inspired by the original [Peppermint theme](https://ghostty.org/docs/config/reference#theme) for [Ghostty](https://ghostty.org/). The color palette and overall aesthetic are adapted from that theme to bring the same terminal-native feel to Zed.

## Installation

### From the Zed Extension Store

1. Open Zed
2. Open the Command Palette (`Cmd-Shift-P` / `Ctrl-Shift-P`)
3. Type `zed: extensions`
4. Search for "Peppermint" and install it

### Manual Installation

1. Copy `themes/peppermint.json` to `~/.config/zed/themes/`
2. Restart Zed
3. Open the Command Palette and run `theme selector: toggle`
4. Select "Peppermint"
