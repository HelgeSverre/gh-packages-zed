# Vercel Carbon for Zed

A Zed theme inspired by Vercel's visual language.

Includes `Vercel Carbon Dark` and `Vercel Carbon Light`.

## Install

### Local (manual)

1. Copy `themes/vercel-carbon.json` to `~/.config/zed/themes/`.
2. Open Zed and run `theme selector: toggle`.
3. Select `Vercel Carbon Dark` or `Vercel Carbon Light`.

### Via Zed Extensions

1. Open Zed Extensions.
2. Search for `Vercel Carbon`.
3. Install and select the theme.
