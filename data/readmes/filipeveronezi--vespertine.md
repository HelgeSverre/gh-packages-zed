# Vespertine

Peppermint and orange flavored light theme for Zed.

Vespertine is a light Zed theme derived from the visual language of [Vesper](https://github.com/raunofreiberg/vesper) by Rauno Freiberg.

## Install locally

Use `zed: install dev extension` and select this repository.

## Attribution

Vespertine adapts Vesper's palette and restrained syntax style for Zed light mode. Vesper is MIT licensed and copyright Rauno Freiberg.
