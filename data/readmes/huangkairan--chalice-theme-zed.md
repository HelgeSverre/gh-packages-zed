# Chalice for Zed

Minimalistic dark/light themes for Zed, ported from Artem Laman's [Chalice color theme for VSCode](https://github.com/artlaman/chalice-color-theme).

Chalice highlights only strings, numbers, comments, and global definitions; everything else uses the editor foreground. No italics, no bold. The aim is to reduce visual noise so you can focus on the structure of your code.

## Install

Once published to the Zed extensions registry, install via `zed: extensions` and search for "Chalice."

For local development:

1. Clone this repository.
2. Open Zed → command palette → `zed: install dev extension` → choose this directory.

Or drop the JSON files into `~/.config/zed/themes/` directly.

## Variants

- **Chalice Dark** — low-contrast teal/green/violet on near-black
- **Chalice Light** — earthy browns/blues on warm off-white
