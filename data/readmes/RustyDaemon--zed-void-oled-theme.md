# Void

A dark theme for [Zed](https://zed.dev) Editor. **Void OLED** uses a true black (`#000000`) background with vivid accents.

## Install

Copy the theme into your Zed themes directory:

```sh
cp themes/void-oled.json ~/.config/zed/themes/
```

... OR install via Zed Extensions

Then pick **Void OLED** via `cmd-k cmd-t` (or `Zed: Select Theme` in the command palette).
