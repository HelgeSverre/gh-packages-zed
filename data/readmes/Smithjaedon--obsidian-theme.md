# Obsidian Dark

A minimal dark theme for [Zed](https://zed.dev) and [VS Code](https://code.visualstudio.com).

Grayscale UI with zero saturation — no colored panels, tabs, or chrome. Syntax colors are clean and muted for readability without distraction.

## Preview

- **Editor**: `#181818`
- **UI surfaces**: `#1a1a1a` to `#252525`
- **Text**: `#cccccc` / `#d4d4d4`
- **Borders**: non-existent (blended with surfaces)

## Installation

### Zed

1. Copy `obsidian.json` to `~/.config/zed/themes/`
2. Open Zed, press `cmd-k cmd-t`, select **Obsidian Dark**

### VS Code

1. Copy the `obsidian-theme` folder to `~/.vscode/extensions/`
2. Reload VS Code (`Developer: Reload Window`)
3. Open Command Palette → `Preferences: Color Theme` → **Obsidian Dark**
