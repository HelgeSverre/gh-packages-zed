# Koda Theme for Zed

A port of [koda.nvim](https://github.com/oskarnurm/koda.nvim) for [Zed](https://zed.dev), generated with [nvim2zed](https://github.com/markosnarinian/nvim2zed).

## Installation

Search for **Koda** in Zed's extension marketplace (`zed: extensions`), or add it manually to your `~/.config/zed/settings.json`:

```json
{
  "theme": "Koda Dark"
}
```

## Variants

- **Koda Dark** — dark variant
