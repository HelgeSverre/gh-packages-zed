# Beyond the Walls: Titan Themes

Nine Titan-inspired color themes for [Zed](https://zed.dev), by **Definitely Not A Titan**. Choose from seven dark palettes and two light palettes, with matching editor, interface, syntax, and integrated terminal colors.

## Themes

| Theme | Appearance |
| --- | --- |
| Titan Slayer Wings | Dark |
| Colossal Breach at Dusk | Dark |
| Titan Hunter Green Cloak | Dark |
| Titan Rumbling March | Dark |
| Within the Walls (Daylight) | Light |
| Potato Girl's Midnight Heist | Dark |
| Titan Nerd Screaming (Goggled Genius) | Dark |
| Tatakae! Titan Rage Teal | Dark |
| Humanity's Strongest Cleaner (Clean or Die) | Light |

## Install

Once this extension is available in the Zed extension registry:

1. Open **Extensions** in Zed (`Ctrl+Shift+X` on Windows/Linux or `Cmd+Shift+X` on macOS).
2. Search for **Beyond the Walls: Titan Themes** and select **Install**.
3. Open the command palette and run **theme selector: toggle**, then choose a theme from the table above.

### Install from source

1. Clone this repository:

   ```sh
   git clone https://github.com/ihssmaheel-dev/zed-titan-themes.git
   ```

2. In Zed, run **zed: install dev extension** from the command palette.
3. Select the cloned repository directory containing `extension.toml`.
4. Run **theme selector: toggle** and choose a theme.

This extension contains only themes; it has no Rust code or language server dependencies.
