# Midnight Theme for Zed

A dark theme with a Nord-inspired color palette featuring deep midnight blues and soft, easy-on-the-eyes colors.

## Installation

### From Zed Extensions

1. Open Zed
2. Open the command palette (`Cmd+Shift+P` on macOS, `Ctrl+Shift+P` on Linux)
3. Search for "zed: extensions"
4. Search for "Midnight Theme"
5. Click Install

### Manual Installation

1. Clone this repository to your Zed extensions directory:
   ```
   git clone https://github.com/aler1x/zed-midnight-theme ~/.config/zed/extensions/midnight-theme
   ```
2. Restart Zed
3. Select the theme from the theme picker

## Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| Background (dark) | `#191c22` | Sidebars, panels |
| Background (editor) | `#1e2127` | Editor background |
| Foreground | `#d8dee9` | Main text |
| Muted | `#7b88a1` | Secondary text |
| Cyan | `#88c0d0` | Functions, accents |
| Teal | `#8fbcbb` | Types, classes |
| Blue | `#81a1c1` | Keywords, operators |
| Green | `#a3be8c` | Strings |
| Yellow | `#ebcb8b` | Warnings, escape chars |
| Orange | `#d08770` | Decorators |
| Red | `#bf616a` | Errors, deletions |
| Purple | `#b48ead` | Numbers, booleans |
