# Vinho

A dark wine theme for [Zed](https://zed.dev): rosy cream text, gold and sage accents. Includes a light mode.

Also available for [Obsidian](https://github.com/rillmind/obsidian-vinho).

## Installation

Clone this repository, run `zed: install dev extension` from the command palette and select the folder.

Or copy `themes/vinho.json` to `~/.config/zed/themes/`.

Then run `theme selector: toggle` and pick *Vinho* or *Vinho Light*.
