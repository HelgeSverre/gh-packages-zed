# Phoenix Pulse Themes for Zed

Phoenix Pulse is a pair of carefully tuned color theme families for
[Zed](https://zed.dev), with dark and light variants for each palette.

## Included themes

| Family | Variants | Character |
| --- | --- | --- |
| Phoenix Pulse EX | Dark, Light | A vivid purple palette with Phoenix orange accents |
| Phoenix Pulse ERL | Dark, Light | A warm earthy palette with deep crimson accents |

## Install

Open Zed's Extensions view, search for `Phoenix Pulse Themes`, and select
**Install**.

Choose a theme by opening the theme selector with `theme selector: toggle`, or
select one under **Settings → Theme**.
