A collection of five carefully crafted themes for the [Zed](https://zed.dev) editor. Astral themes are built around a single principle: **coding should feel effortless**. Every color choice prioritizes readability and reduced eye strain without sacrificing elegance.

## Installation

### Via Zed Extensions Panel

1. Open Zed
2. Press `Cmd+Shift+X` (macOS) or `Ctrl+Shift+X` (Linux/Windows) to open Extensions
3. Search for **Astral Themes**
4. Click **Install**

### Activate a Theme

1. Open the command palette (`Cmd+Shift+P` / `Ctrl+Shift+P`)
2. Run **`theme selector: toggle`**
3. Search for any **Astral** theme and select it

## Design Philosophy

Astral themes are designed for **long coding sessions**. The guiding principles behind every palette:

- **Reduced eye strain** — contrast ratios are tuned to be readable without being harsh
- **Semantic clarity** — syntax colors are chosen to make code structure immediately obvious
- **Aesthetic cohesion** — UI chrome, editor, and terminal share a unified color language
- **Dark and light balance** — both variants are first-class; neither is an afterthought
