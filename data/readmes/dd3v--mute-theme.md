# Mute

A minimalistic dark theme for [Zed](https://zed.dev).

![Mute theme screenshot](./screenshot.png)

## Install

Copy `mute.json` into `~/.config/zed/themes/`, then pick **Mute** from `Cmd-Shift-P` → `theme selector: toggle`.

## Icons & font

- Icons: [Monospace Icon Theme](https://github.com/PowerCord01/zed-monospace-icon-theme) - `"icon_theme": { "dark": "Monospace Icon Theme - Dark" }`
- Font: [JetBrains Mono](https://www.jetbrains.com/lp/mono/) -  `"buffer_font_family": "JetBrains Mono"`
