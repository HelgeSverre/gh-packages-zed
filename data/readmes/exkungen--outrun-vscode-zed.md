# Outrun (VS Code Port) for Zed

A faithful port of the [Outrun VS Code theme](https://github.com/samrap/outrun-theme-vscode) by [Sam Rapaport (samrapdev)](https://github.com/samrap) — a theme inspired by the colors, style, and culture of the synthwave music scene.

All colors are taken directly from the original theme. Two variants are included:

- **Outrun Night (VS Code)** — `#161130` editor background
- **Outrun Electric (VS Code)** — higher-contrast `#0c0a20` editor background

## Installation

Search for **Outrun (VS Code Port)** in Zed's extension browser (`cmd-shift-x`), install, then pick the theme with `cmd-k cmd-t`.
