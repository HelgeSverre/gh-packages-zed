# Dark Foundry Theme

A curated dark theme collection with aurora, graphite and sakura-inspired palettes.

## Included themes

- `Obsidian Aurora`
- `Ember Graphite`
- `Nocturne Sakura`

## Local development

Install as a dev extension in Zed:

1. Open the command palette.
2. Run `zed: install dev extension`.
3. Select this directory.
4. Reload Zed and open the theme selector.
