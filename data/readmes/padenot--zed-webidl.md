# `zed-webidl`

What it says on the tin, allows highlighting
[WebIDL](https://webidl.spec.whatwg.org/) files in [Zed](https://zed.dev/). This
is the language in which the Web APIs are defined.

This uses https://github.com/padenot/tree-sitter-webidl, that has been written
for this Zed extension.
