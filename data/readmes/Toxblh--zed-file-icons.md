# File Icons for Zed

A port of the popular [file-icons/vscode](https://github.com/file-icons/vscode) icon theme for the [Zed](https://zed.dev) editor.

Over 2,000 icons for files, folders, and languages — covering virtually every file type you'll encounter.

![File Icons for Zed](assets/screenshot.png)

## Installation

1. Open the Extensions panel: `Cmd+Shift+X` (macOS) / `Ctrl+Shift+X` (Linux)
2. Search for **File Icons**
3. Click **Install**
4. Set the icon theme in your settings:

```json
  "icon_theme": {
    "mode": "system",
    "light": "File Icons Light",
    "dark": "File Icons"
  },
```

Or via Command Palette → `icon theme selector: toggle` → select **File Icons**.

Configure dynamic change depend on system theme
